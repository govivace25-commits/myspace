조선의 국보 동궐도(東闕圖) 속 전각과 궁문, 길과 다리를 현대적인 인터랙티브 지도로 재해석한 아카이브입니다. 원하는 위치를 클릭하여 건물명, 한자 표기, 건축 시기, 역사적 유래를 손쉽게 기록하고 누구나 직관적으로 탐색할 수 있습니다.

✨ 핵심 기능

  • 📍 새 장소 등록 모드 : 상단 버튼 클릭 후 지도 위 원하는 위치를 클릭해 새로운 건물이나 도로를 등록합니다.
  • 📝 상세 정보 기록 : 구분(건물·문·도로·기타), 한글명, 한자, 건축/조성 시기, 상세 유래를 체계적으로 작성합니다.
  • 📜 목록 탐색기 (드로어) : 등록된 모든 장소를 검색 및 유형별 필터링할 수 있으며, 클릭 시 해당 위치로 부드럽게 자동 이동합니다.
  • 📖 서책 스타일 상세 패널 : 마커 클릭 시 궁궐의 고풍스러운 한지 서책 디자인으로 상세 정보를 열람하고 수정·삭제할 수 있습니다.
  • 💾 데이터 보존 & 백업 : 등록된 데이터는 안전하게 보관되며, JSON 파일로 내보내기/불러오기가 가능합니다.
